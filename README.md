## 💡 Nedir ve Neden TonoScan?

**TonoScan**, telefonunuz ile bilgisayarınız arasındaki dosya ve belge aktarma sürecini baştan tanımlayan modern bir web istasyonudur. 

USB kablosu aramakla uğraşmadan, telefonunuza hantal mobil uygulamalar yüklemeden veya gizliliğinizi WhatsApp Web / e-posta gibi kanallara emanet etmeden; sadece **bilgisayar ekranındaki karekodu telefonunuzla okutarak** saniyeler içinde şifreli bir köprü kurarsınız.

Telefonda çektiğiniz belgeler, seçtiğiniz fotoğraflar veya 250 MB'a kadar büyük boyutlu dosyalar bilgisayarınızda **anında belirir**. Üstelik dahili **PDF Stüdyosu** ve **Kolaj Düzenleyicisi** sayesinde sayfaları sürükleyip sıralayabilir, kırpabilir, tek tıkla yüksek çözünürlüklü PDF'e çevirebilirsiniz.

## ✨ Öne Çıkan Yetenekler

### 📱 1. Temassız & Anında Karekod Eşleşmesi
- PC'de sayfayı açtığınız anda özel, tek kullanımlık bir şifreli oda anahtarı üretilir.
- Telefon kamerasıyla karekodu okuttuğunuz an bağlantı kurulur. Bilgisayar ekranından onay verdiğiniz cihazlar doğrudan dosya transferine başlar.

### 📑 2. Seçim Sırasına Göre PDF'e Dönüştürme & Birleştirme
- **Tek Görsel Seçimi:** Görselinizi doğrudan tek tıkla `Sığdır`, `Doldur` veya `Orijinal Oran` seçenekleriyle PDF yapın.
- **Çoklu Görsel Seçimi:** Seçtiğiniz 10'larca fotoğrafı, seçim sıranıza göre tek bir PDF belgesinde birleştirin.
- **Görsel & PDF Karışık Birleştirme:** Hem mevcut PDF dosyalarınızı hem de yeni çektiğiniz fotoğrafları tek bir tıklamayla tek çatı altında toplayın.
- Alt seçim dock'unda küçük resimleri sürükleyerek sayfa sırasını anında değiştirin.

### 🛠️ 3. Profesyonel PDF Sayfa Düzenleyici (PDF Studio)
- **Sayfa Sıralama:** Sayfaları sürükle-bırak ile dilediğiniz gibi yer değiştirin.
- **Döndürme & Kesme (Crop):** Ters gelen evrakları 90° döndürün veya tutamaçlarla kenarlık fazlalıklarını kesin.
- **Sayfa Yönetimi:** İstenmeyen sayfaları silin, önemli sayfaları kopyalayın, araya boş sayfa ekleyin.
- **Esnek Dışa Aktarım:**
  - *Klasöre Kaydet:* Sonucu doğrudan TonoScan arşivine ekler.
  - *İndir:* Tek birleştirilmiş PDF olarak bilgisayara indirir.
  - *Her Sayfayı Ayrı PDF Yap:* Sayfaları ayırarak arşivler.
  - *ZIP İndir:* Tüm sayfaları ayrı ayrı numaralandırıp tek ZIP paketi olarak sunar.

### 📁 4. Cihaz Bazlı Klasörleme & Ekmek Kırıntısı (Breadcrumbs)
- Dosyalar ana ekranda düzensizce yığılmaz; her bağlanan cihazın kendine özel bir **klasör kartı** oluşturulur (örn: *Burak*, *Hasan* vb.).
- Kullanıcı tek tıkla herhangi bir cihaz klasörünün içine girebilir, o cihaza ait dosyaları yönetebilir veya "Tüm Dosyalar" görünümüne dönebilir.
- Dosya kartlarındaki cihaz etiketine veya sol cihaz listesindeki herhangi bir cihaza tıklanarak doğrudan o cihazın klasörüne geçilebilir.

### 🏷️ 5. Benzersiz Cihaz Adlandırma & Çakışma Önleme
- Her bağlanan telefona sistem tarafından kolay hatırlanabilir, akıllı ve Türkçe bir cihaz adı atanır (örn: *Cesur Kartal*, *Hızlı Şahin* vb.).
- Kullanıcı dilediği an cihaz adını telefonundan değiştirebilir.
- Eğer oturumda aynı ada sahip aktif bir cihaz varsa, sistem bunu algılar ve kullanıcıyı uyararak yeni bir ad seçmesini ister.

### 📱 6. Mobil Karşılama Ekranı (Hub) & Pil Tasarrufu
- Karekod okutulduktan sonra telefon doğrudan gereksiz yere kamerayı açık bırakıp pili tüketmez.
- Şık bir **Mobil Hub** açılır: Kullanıcı isterse "Kamera ile Çek / Tara", isterse doğrudan "Galeri" veya "Dosya" butonuna dokunarak aktarım yapar.
- Kamera vizöründe yer alan **Geri / Menü** butonu sayesinde kullanıcı istediği an çekimi sonlandırıp ana menüye dönebilir ve kamera donanımı arka planda durdurulur.
- Karekod tarayıcı ekranında uçtan uca AES-256 şifreli bağlantı rozeti ve anlaşılır bilgilendirme üst barı bulunur.

### 🎨 7. Kolaj ve Evrak Düzenleyici (A4 / A5 / Letter)
- Kimlik ön-arka çekimlerini, faturaları veya sözleşmeleri A4 sayfasına hazır şablonlarla (2'li alt alta, yan yana, 4'lü, 6'lı ızgara) dizin.
- Hassas hizalama kılavuzları, 1 mm adım ok kontrolleri ve "Net Evrak / Fotokopi" filtreleri.

### 💾 8. Bilgisayar Klasörüne Otomatik Kaydetme
- Chrome ve Edge tarayıcılarının modern *File System Access API* desteği sayesinde; telefondan gelen her evrak, bilgisayarınızda belirlediğiniz klasöre (örn: `İndirilenler/Evraklar`) otomatik olarak yazılır.

### 📷 9. Mobil Vizör & Akıllı Belge Çekim Modu
- **A4 / 3:4 / Tam Ekran Maskesi:** Çekmek istediğiniz belgenin oranına göre vizör sınırlandırılır.
- **Çoklu Sayfa (Belge) Modu:** Sayfaları art arda çekin, "Bitir ve PDF Gönder" butonuna bastığınız anda tüm sayfalar telefonda tek PDF yapılıp bilgisayara şifreli uçurulur.
- **Flaş & Ön/Arka Kamera:** Tek dokunuşla fener kontrolü ve kamera geçişi.

## 📂 Proje Dosya Mimarisi

TonoScan, herhangi bir harici derleyiciye (*compiler*), paketleyiciye (*bundler*) veya framework'e ihtiyaç duymayan **Pure Vanilla Web Architecture** ile hazırlanmıştır. Geliştirme ve bakım kolaylığı için modüler parçalara ayrılmıştır:

```text
TonoScan/
│
├── 📄 index.html             # Semantik, temiz, optimize edilmiş ana sayfa ve modallar
├── 📄 README.md               # Detaylı tanıtım, mimari ve kurulum dokümantasyonu
│
├── 📁 css/                   # Tasarım Katmanı
│   ├── style.css             # Tema değişkenleri, aurora arka planı, butonlar, glassmorphism
│   ├── pc.css                # Masaüstü paneli, üst bar, cihaz listesi, dosya kartları ve dock
│   ├── mobile.css            # Mobil vizör, kamera kontrolleri, vizör maskesi, QR tarayıcı
│   └── modals.css            # PDF stüdyosu, kolaj penceresi, görsel kırpıcı ve yardım modalları
│
└── 📁 js/                    # Mantık ve İşlev Katmanı
    ├── config.js             # Firebase ayarları, sabitler (MAX, CH, PAL), yardımcı araçlar
    ├── crypto.js             # AES-256-GCM uçtan uca şifreleme motoru ve Firebase köprüsü
    ├── storage.js            # IndexedDB yerel veritabanı motoru ve anlık önizleme (thumbnail)
    ├── pool.js               # Ortak kota havuzu, otomatik dosya temizliği ve yerel klasör izni
    ├── editor.js             # Tekil görsel cropper, evrak netleştirme ve dikey birleştirme
    ├── collage.js            # A4/A5/Letter kolaj stüdyosu, sürükle-bırak canvas yerleşimi
    ├── pdf-editor.js         # Gelişmiş PDF sayfa düzenleyici, birleştirme, kırpma motoru
    ├── pc.js                 # PC arayüzü, şifreli parça alıcı (inbox), dosya gezgini
    ├── mobile.js             # Mobil kamera akışı, vizör oranları, parça parça şifreli yükleyici
    └── app.js                # Başlatıcı (Bootstrap), cihaz algılayıcı ve yönlendirici
```

## 🔒 Güvenlik ve Gizlilik Mimarisi

TonoScan **Sıfır Bilgi (Zero-Knowledge)** ilkesiyle tasarlanmıştır:

```
[ Telefon (İstemci) ]                                    [ Bilgisayar (İstemci) ]
         |                                                          |
         | --- 1. Kamera ile QR Okuma (#r=ODA&k=ANAHTAR) ----------> |
         |                                                          |
         |  * Dosya telefonda parçalara bölünür                     |
         |  * Her parça AES-256-GCM ile şifrelenir                 |
         |                                                          |
         | --- 2. Şifreli Parçalar Geçici Olarak Gönderilir -------> |
         |                  [ Firebase RTDB Köprüsü ]                |
         |                    (Sadece anlık geçiş)                  |
         |                                                          |
         |                                    * PC parçayı teslim alır
         |                                    * Anahtarla çözer (AES-GCM)
         |                                    * Parça sunucudan silinir
         |                                    * Dosya IndexedDB'ye yazılır
```

1. **Şifre Anahtarı Asla Sunucuya Gitmez:**  
   Şifreleme anahtarı (`k`), karekodun URL'sinde **`#` (URL Hash)** sonrasında yer alır. Tarayıcı standartları gereği hash parametreleri sunuculara HTTP isteği olarak hiçbir zaman iletilmez.
2. **Kalıcı Sunucu Depolaması Yoktur:**  
   Firebase veritabanı yalnızca şifreli veri bloklarının transferi için geçici bir tampon köprü görevi görür. Parça bilgisayar tarafından alındığı anda veritabanından kalıcı olarak silinir.
3. **Cihaz Doğrulama Güvenliği:**  
   Aynı karekodu okutan yabancı cihazların dosyaları doğrudan kabul edilmez; bilgisayar ekranında onay istemi belirir.

## 🌐 GitHub Pages ile 1 Dakikada Yayınlama

TonoScan'i kendi GitHub hesabınızda barındırmak tamamen ücretsizdir:

### 1. Depoyu Klonlayın veya Kendi Hesabınıza Push Edin
```bash
git init
git add .
git commit -m "feat: Initial commit with modular TonoScan"
git branch -M main
git remote add origin https://github.com/KULLANICI_ADINIZ/TonoScan.git
git push -u origin main
```

### 2. GitHub Pages'i Aktif Edin
1. GitHub deponuzda **Settings (Ayarlar)** sekmesine tıklayın.
2. Sol menüden **Pages** bölümüne gelin.
3. **Build and deployment > Source** alanında:
   - Branch: `main`
   - Folder: `/ (root)` seçin ve **Save** butonuna tıklayın.
4. Yaklaşık 30 saniye içinde siteniz `https://KULLANICI_ADINIZ.github.io/TonoScan/` adresinde canlıya çıkacaktır!
